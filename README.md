# Portfolio — Utkarsh Raj

> **From an idea to a working product.**
> Full-stack developer building software that solves real problems.

Personal portfolio website built with React 19, TypeScript, Tailwind CSS v4, and Motion. Features an interactive terminal shell, production MERN & AI applications, categorized skills, and the Smart Building Energy Optimizer (Python + ML) exploration.

---

## Tech Stack

- **Frontend:** React 19, Vite, TypeScript, Tailwind CSS v4, Motion
- **Fonts:** Instrument Serif & JetBrains Mono Variable
- **Contact:** Web3Forms API
- **Deployment:** Vercel

---

## Featured Work

1. **[AI Interview Analyser (Flagship)](https://utkarsh1-ux-gen-ai-fullstack-fronte.vercel.app/)**
   - An AI-powered mock interview platform that generates role-specific questions from a candidate's resume and provides personalized interview coaching.
   - **Stack:** React, Node.js, Express, MongoDB, Google Gemini API, JWT Authentication, REST APIs.
   - **Workflow:** `Upload Resume → Select Job Role → Generate Interview → Receive Feedback`

2. **[E-Commerce Clothing Website](https://the-clothing-brand-frontend-react.vercel.app/)**
   - Production storefront paired with an end-to-end admin inventory and order management dashboard.
   - **Stack:** React, Node.js, Express, MongoDB, REST APIs, Tailwind CSS.

3. **Smart Building Energy Optimizer (Currently Exploring & Researching)**
   - Python-based energy management platform for offices, colleges, and commercial buildings.
   - Utilizes Python (Django REST Framework), Pandas, and Scikit-learn to analyze room-wise electricity consumption, detect unoccupied wastage anomalies, and forecast future demand.
   - **Stack:** React, Tailwind CSS, Recharts, Python, Django REST Framework, PostgreSQL, Pandas, NumPy, Scikit-learn.

## Run Locally

```bash
# Clone the repository
git clone https://github.com/Utkarsh1-ux/Portfolio_MERN.git
cd Portfolio_MERN

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to explore the site.
