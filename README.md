# Portfolio MERN — Utkarsh Raj

A modern, minimalist personal portfolio engineered with **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Motion**. Built to showcase full-stack MERN & GenAI applications, technical capabilities, and projects to engineering teams and interviewers.

---

## ⚡ Highlights & Features

- **Interactive Shell Terminal**: An interactive in-browser terminal emulator (`~/utkarsh — zsh`) supporting keyboard navigation, command suggestions, and executable commands (`help`, `about`, `projects`, `open <1|2>`, `skills`, `recognition`, `contact`, `resume`, `clear`).
- **Live Contact Form**: Seamless direct-to-inbox messaging powered by Web3Forms with real-time validation, bot honeypot protection, and fallback states.
- **Editorial Typography & Dark Aesthetic**: Powered by *Instrument Serif* and *JetBrains Mono*, architectural blueprint layouts, subtle grid rules, and fluid typography.
- **Micro-interactions & Motion**: Smooth scroll reveals, page entry loaders, hover physics, and full support for reduced-motion preferences.
- **Production-Ready & Responsive**: Optimized for zero-config static hosting (Vercel, Netlify, Cloudflare Pages) with type-safe architecture.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite 8, TypeScript 7
- **Styling**: Tailwind CSS v4, JetBrains Mono Variable, Instrument Serif
- **Animation**: Motion (`motion/react`)
- **Icons**: Lucide React
- **Form Delivery**: Web3Forms API
- **Deployment**: Vercel

## 💻 Getting Started Locally

### Prerequisites
- Node.js >= 20
- npm >= 9

### Installation

```bash
# Clone the repository
git clone https://github.com/Utkarsh1-ux/Portfolio-MERN.git
cd Portfolio-MERN

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` to view the site.

### Build & Typecheck

```bash
# Typecheck TypeScript
npm run typecheck

# Production build into dist/
npm run build

# Preview production build locally
npm run preview
```
