# Portfolio — Utkarsh Raj

My personal portfolio website built with React, TypeScript, and Tailwind CSS. Features an interactive terminal shell, my full-stack MERN & AI projects, and a working contact form.

---

## Tech Stack

- **Frontend:** React 19, Vite, TypeScript, Tailwind CSS v4, Motion
- **Contact:** Web3Forms API
- **Design:** Instrument Serif & JetBrains Mono

---

## Featured Projects

1. **[AI Interview Analyser](https://utkarsh1-ux-gen-ai-fullstack-fronte.vercel.app/)** — Mock interview platform built with Google Gemini API, Node.js, and JWT auth.
2. **[E-Commerce Clothing Store](https://the-clothing-brand-frontend-react.vercel.app/)** — Full-stack clothing store with cart, checkout, and an admin dashboard.

## Run Locally

```bash
# Clone the repository
git clone https://github.com/Utkarsh1-ux/Portfolio_MERN.git
cd Portfolio_MERN

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to view the site.
